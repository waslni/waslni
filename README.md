# وصلني | Waslni

موقع ثابت لعرض باقات «وصلني» ومعرض الأعمال. لا توجد حسابات للعملاء أو قاعدة بيانات للطلبات. يجهز الموقع ملخص طلب في متصفح العميل ثم يفتح واتساب ليرسله بنفسه إلى الموظف.

## إدارة الموقع

تتوفر لوحة مدير من رابط **دخول المدير** في أسفل الموقع. تسجيل الدخول يتم بحساب GitHub الذي لديه صلاحية الكتابة على المستودع، باستخدام Fine-grained personal access token محدود للمستودع وبصلاحية `Contents: Read and write` فقط. يحفظ الرمز داخل جلسة المتصفح ولا يدخل في ملفات الموقع.

من اللوحة يستطيع المدير تعديل رقم واتساب، وصف المنصة، أسعار الباقات ومميزاتها، ورفع الصور والفيديوهات وإضافتها إلى المعرض. تحفظ اللوحة التعديلات كملفات في GitHub، ثم ينشرها GitHub Actions إلى Pages.

راجع [دليل لوحة المدير](CONTENT_MANAGEMENT_GITHUB_AR.md) لإعداد رمز GitHub والدخول والرفع.

## التطوير المحلي

يتطلب Node.js 22.

```bash
npm ci
npm run dev
```

## أوامر المشروع

- `npm run dev`: تشغيل محلي.
- `npm run build`: تجهيز نسخة النشر.
- `npm run lint`: فحص lint.
- `npm run preview`: معاينة البناء.

مجلدات `supabase/` و`public/api.php` وخدمات الإصدار السابق باقية كمرجع تاريخي؛ واجهة الموقع واللوحة الحالية تعملان عبر ملفات GitHub ولا تتصلان بها.
